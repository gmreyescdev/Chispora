# Ruta personal de aprendizaje

## Enfoque

Aprenderemos cada concepto cuando Chispora lo necesite. Esto evita estudiar herramientas aisladas sin comprender para qué sirven.

## Etapa 1 — Fundamentos de la web

Aplicación en Chispora: portada, navegación y primer tablero de Memorama.

- HTML semántico: estructura y significado del contenido.
- CSS: presentación, diseño adaptable y estados visuales.
- JavaScript: reglas, eventos, estado y actualización de la interfaz.
- Herramientas del navegador: inspección, consola y depuración.

Meta personal: poder explicar qué responsabilidad tiene cada tecnología y localizar un error sencillo.

## Etapa 2 — Trabajo profesional

Aplicación en Chispora: desarrollar funciones sin perder versiones anteriores.

- Git: repositorio, cambios, commits y ramas.
- Organización de archivos y convenciones.
- Lectura de errores y depuración sistemática.
- Accesibilidad y diseño adaptable.
- Pruebas manuales y automatizadas.

Meta personal: construir una mejora, probarla y dejar un commit comprensible.

## Etapa 3 — Diseño de software

Aplicación en Chispora: reutilizar reglas entre varios juegos.

- Separación entre datos, reglas y presentación.
- Componentes reutilizables.
- Estado de la aplicación.
- Manejo de errores y casos límite.
- Rendimiento y funcionamiento sin conexión.

Meta personal: entender el recorrido de una acción desde el clic hasta el resultado visible.

## Etapa 4 — Producto conectado

Se abordará únicamente después de validar el MVP.

- HTTP y API.
- Backend y base de datos.
- Autenticación de adultos y perfiles infantiles.
- Privacidad, seguridad y copias de respaldo.
- Despliegue, registros y monitoreo.

Meta personal: comprender dónde viven los datos, quién puede acceder y cómo se recupera el sistema ante un fallo.

## Etapa 5 — Producto y negocio

- Entrevistas y validación del problema.
- Métricas respetuosas con la privacidad.
- Costos, precios y margen.
- Soporte y operaciones.
- Ventas familiares y escolares.
- Marca, contratos y obligaciones legales.

Meta personal: diferenciar una función atractiva de una función que aporta valor y puede sostener un negocio.

## Método para estudiar cada tema

1. Explicación sencilla.
2. Ejemplo pequeño.
3. Aplicación real en Chispora.
4. Prueba o experimento.
5. Explicación escrita con tus propias palabras.

## Preguntas de control

Al terminar cada etapa deberías poder responder:

- ¿Qué problema resolvimos?
- ¿Qué archivos cambiaron?
- ¿Cómo circulan los datos?
- ¿Cómo comprobamos que funciona?
- ¿Qué alternativa descartamos y por qué?
- ¿Qué riesgo queda abierto?
