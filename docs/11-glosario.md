# Glosario técnico

## API

Un contrato que permite que dos sistemas intercambien información. Una futura aplicación de Chispora podría pedir a una API el progreso guardado de un perfil.

## Backend

La parte del sistema que se ejecuta en un servidor. Procesa reglas, usuarios y datos que deben compartirse entre dispositivos.

## Base de datos

Sistema organizado para guardar y consultar información persistente.

## Commit

Una fotografía identificada de un conjunto de cambios en Git. Debe contar una unidad de trabajo comprensible.

## CSS

Lenguaje que define la apariencia y distribución visual de una página web.

## Dominio

Dirección legible de un sitio, por ejemplo `chispora.cl`. No equivale a una marca comercial.

## Frontend

La parte visible e interactiva que se ejecuta en el navegador del usuario.

## Git

Sistema de control de versiones. Conserva el historial de cambios y permite comparar o recuperar estados anteriores.

## HTML

Lenguaje que estructura el contenido y expresa su significado: títulos, botones, formularios y secciones.

## JavaScript

Lenguaje que implementa el comportamiento de la aplicación: clics, reglas, puntuaciones y cambios en pantalla.

## localStorage

Espacio del navegador para guardar pequeñas cantidades de información en un dispositivo. No sincroniza automáticamente entre equipos.

## MVP

Producto mínimo viable: la versión más pequeña que permite comprobar una hipótesis con usuarios reales.

## PWA

Sitio web que incorpora capacidades similares a una aplicación, como instalación y funcionamiento parcial sin conexión.

## Repositorio

Carpeta cuyo contenido e historial son administrados por Git.

## SaaS

Software ofrecido como servicio a través de Internet, normalmente mediante una suscripción.

## UX

Experiencia de usuario: facilidad, claridad y sensaciones producidas al utilizar el producto.

## UI

Interfaz de usuario: botones, colores, tipografía, pantallas y otros elementos visibles.
